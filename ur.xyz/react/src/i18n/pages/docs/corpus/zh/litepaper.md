# 在 Bittensor 上协调的隐私网络

> 掌控你的隐私，掌控网络。

## I. 去中心化隐私网络

UR 是一个去中心化隐私网络。它通过多跳路由和分层加密，把用户流量分散到由独立矿工组成的全球网络中，因此没有任何一个矿工能同时看到用户是谁以及用户在做什么。其传输被设计得与普通 HTTPS 相似，采用 N 层 TLS 加密、SNI 伪装和流量不可区分性，因此网络几乎在任何地方都能访问。

UR 子网，即 Bittensor SN25（netuid 25），通过链上激励来协调这个网络。网络运营商运行服务器；独立矿工承载入口和出口流量；独立验证者持续遍历由运营商分配的矿工链，以证明实时传输，并测量哪些矿工是最薄弱的环节。这种测量是网络为之付费的核心信号。

Bittensor 的 Yuma Consensus 将验证者的测量结果转化为代币发行，Subtensor EVM 上的智能合约负责结算支付。该协议是开源的，运行矿工或验证者无需任何许可。

## II. 角色

网络运营商运行隐私服务器和验证端点。运营商向子网存入存款，共同签署每条被测量的路径，并提交一份支付列表，把其奖励分配给连接到它的矿工。运营商报告其奖励所依据的使用量，但从不持有任何他人的资金。

矿工是网络的入口和出口。他们采用默认安全的安全模型，屏蔽已知的恶意 IP，并且只路由加密流量。一个矿工为一个或多个运营商承载流量，并因其承载的流量获得报酬；在顶级集群中，还会因其贡献的可路由容量获得报酬。

验证者是独立的。每个验证者质押自己的 UR，运行路由验证协议，并按需求和实测质量为每个运营商的池评分。验证者因准确且与共识一致的评分而获得网络的原生分红。没有任何运营商拥有验证者，验证者集合也无需许可即可加入。

子网所有者管理结算合约中可升级的协调器，而不是保存矿工奖励的不可变金库，并运营网络的储备。这一角色是过渡性的：控制权起初是集中但有边界的，随后逐步去中心化，如第 V 条所述。

## III. UR 代币

UR 是子网的原生代币，是存款、发行和结算的记账单位。它是一种用于协调网络资源并为其付费的实用型代币；其设计并非用于代表或提供任何获得利润、收入或回报的权利。

新的 UR 由 Bittensor 的 coinbase 每一轮发行，并分为三部分：

| 流向 | 份额 | 接收方 |
| --- | ---: | --- |
| 所有者 | 18% | 子网所有者 |
| 矿工 | 41% | 提供者获得 momentum 份额（启动时为 10%），通过运营商池和顶级矿工槽位发放；其余部分归 Network Capacity Reserve |
| 验证者 | 41% | 独立验证者，因准确评分而获得原生分红 |

运营商按其实际使用量、以公布的参考费率存入 UR，为网络提供资金。存款是由收入支撑的真实需求信号：合约会把每笔存款转入子网储备。运营商的累计存款会降低其必须缴纳的费率，因此坚定投入的运营商可以用更少的前期资本加入。在初始阶段，公布的费率为 0，不需要存款，每个运营商池都被赋予相同的需求，因此只有实测质量在引导池通道。

矿工的报酬来自发行，而不是存款。由于存款累积在储备中，而不是被循环用于支付，真实使用会增加对代币的需求，而发行则遵循带有减半的固定时间表。

## IV. 两种赚取方式

一个运营商可以服务远超 100,000 个矿工，远多于子网大约 256 个链上槽位，因此网络通过两个并行运行的层级向矿工付费。

池是入门通道。每个运营商为其所有矿工持有一个链上槽位；验证者按运营商的需求及其实测质量为该池赋予权重，每个矿工凭密码学证明直接从结算合约领取自己的份额。没有需要争夺的槽位，也没有需要销毁的东西。这是矿工起步并赚取基线奖励的地方。

在池旁边、同一层级中，每个运营商从第 8 周期起还有一个夺旗池，在每个国家设有十个奖励槽位：五个给提供者，五个给扩展器。运营商的矿工凭池的注册即可进入，无需销毁任何东西。每个周期，一次公开抽签从符合条件的矿工中填满这些槽位：这些矿工在至少半个周期内保持在线、通过运营商的检查并位于该国，且在周期结束时处于活跃状态；无人赢得的槽位会结转到该国对应角色的累积池中。夺旗占提供者份额的十分之一。

顶级矿工是供给的顶端。大约 200 个最大的集群按其实际服务的不同的可路由出口 IP 数量（而非流量大小）排名，各自领取自己的链上槽位，并由网络直接付费，支付路径中没有运营商。共享 IP 会在认领它的各集群之间拆分，因此覆盖广度不能被重复计算。

两个层级构成同一场竞赛：矿工从池中起步，随着可路由 IP 广度的增长晋升到顶级槽位，若广度下滑则退回池中。一个由治理设定的比例在头部和尾部之间分配提供者的发行份额。

- 池层级：入门通道。加入一个运营商，无需槽位，也没有注册成本；验证者按需求和质量为池赋予权重；每个矿工的份额在每个结算期累积，并凭证明领取（在结算 v2 下，进入一个永不过期的账户）。
- 顶级矿工：顶端。可路由 IP 覆盖最广的大约 200 个集群领取自己的槽位，并由网络直接付费，没有运营商、池或中间方。

## V. 托管、结算与去中心化

结算以七天为一轮进行。合约在整个期间内累积每个池的发行，然后开放领取：矿工依据其运营商提交的支付列表，直接从合约中提取自己的 UR。在结算 v2 下，支付根只有在验证者批准且 14,400 个区块的挑战窗口过去之后才会开放，账户余额永不过期。顶级矿工不需要结算步骤，因为链会在每一轮原生地向其槽位付费。

没有人持有他人的资金。结算合约是在途 UR 的唯一托管方，每一笔池支付都是直接的链上领取，顶级矿工则被原生地支付到自己的密钥。运营商和所有者从不托管矿工的奖励。

已赚取的领取权是最终的。一旦某个结算期被最终确定，支撑其领取的代币即被锁定。任何合约升级、暂停或管理操作都无法阻止或撤销它们；只有在链层面禁用 SN25 上质押转账的开关能够冻结领取，而它也无法拿走或转移这些领取权。

控制权随时间去中心化。网络启动时，其策略协调器可通过所有者 multisig 升级，为早期的错误修复提供有意设计、有边界的集中控制；而结算金库和存款储备从第一天起就不可变，一个只能暂停的守护者可以阻止漏洞利用，但永远无法转移资金或阻止已最终确定的领取。它会分阶段加固：对每一次变更实施公开的时间锁，并在适当时候实现链上治理。
