# So löschst du dein Konto

Im Bereich Account -> Settings (Konto -> Einstellungen) findest du die Schaltfläche Delete Account (Konto löschen). Tippe darauf und bestätige. Dein Netzwerk und die zugehörigen Informationen werden unwiderruflich und dauerhaft von der Plattform gelöscht.
