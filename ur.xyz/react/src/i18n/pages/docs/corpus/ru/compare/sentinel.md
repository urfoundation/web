## Рядом

| | Майнер UR | Sentinel |
| --- | --- | --- |
| Что вы запускаете | Программа `provider` на компьютере с Linux, macOS или Windows, который остаётся в сети, с одним стабильным публичным адресом и входящим TCP-портом 443 для его extender | Узел dvpnx в Docker на Linux (предпочтительно Debian или Ubuntu) с 2 vCPU, 2 ГБ ОЗУ, SSD на 10 ГБ, безлимитным трафиком и публичным IP |
| Прочие требования | Аккаунт у оператора сети и coldkey Bittensor | Баланс P2P на аккаунте узла для ончейн-транзакций и пройденная проверка работоспособности для права на вознаграждения |
| Как задаются вознаграждения | Доля эмиссии майнеров подсети, пропорциональная выполненному трафику, умноженному на измеренную надёжность; платный и бесплатный трафик приносят одинаково | Пользователи dVPN платят узлу за ГБ или за час по ценам, которые задаёт оператор, либо через планы подписки, оплачивающие каждый час работы |
| Актив выплаты | α ($UR) в виде нативного стейка α на вашем coldkey | P2P, выплачивается каждый час |
| Кошелёк или KYC | Coldkey Bittensor, который вы подтверждаете подписанным заявлением; цитируемые страницы не описывают проверки личности | Аккаунт узла — это кошелёк; проверка личности не задокументирована |
| Клиент с открытым кодом | Руководство следует исходному коду `sn/miner` на GitHub | Публичный репозиторий; лицензия не подтверждена на проверенных страницах |
| Трафик, который вы передаёте | Интернет-трафик оператора сети, в роли его точки выхода | Трафик пользователей приложений dVPN |
| Кто несёт ответственность | Не рассматривается на цитируемых здесь страницах; прочитайте условия своего оператора | Не задокументировано на проверенных страницах |
| Данные и удаление | Майнер хранит свою идентичность и историю кошелька в `~/.urnetwork`; удаление на цитируемых страницах не рассматривается | Не задокументировано на проверенных страницах |

## Чем различаются вознаграждения

Майнер UR в пуле оператора получает долю пула: выполненные байты использования, умноженные на надёжность, где надёжность — это подтверждения, делённые на назначения. Эту работу измеряют валидаторы; цены за байт нет. Вознаграждения считаются по эпохам — примерно неделя в mainnet — и забираются после неё.

Страница Sentinel о заработке описывает два способа получения оплаты. План подписки блокирует токены за выбранными узлами и платит за каждый час работы. Пользователи с оплатой по факту платят за ГБ или за час по ценам, которые оператор задаёт в долларах США, а оракул пересчитывает в P2P. Стейкеры P2P также получают долю платежей за трафик.

## В чём выигрывает Sentinel

- **Цены, которые задаёте вы:** узел сам устанавливает цены за ГБ и за час.
- **Ежечасные выплаты:** вознаграждения узла выплачиваются каждый час, без шага получения.

## Чем вы жертвуете с UR

- Настройка в командной строке, открытые порты и подписанное заявление кошелька Bittensor.
- Получение вознаграждений после закрытия каждой эпохи с помощью ключа ретранслятора, на котором есть немного TAO для оплаты газа.
- Нет цены, которую вы задаёте за свою пропускную способность.
- Цитируемые здесь страницы не говорят, кто отвечает за выходной трафик; это говорят условия вашего оператора.
