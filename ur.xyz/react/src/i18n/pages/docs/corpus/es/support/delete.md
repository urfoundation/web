# Cómo eliminar tu cuenta

En la sección Account -> Settings (Cuenta -> Ajustes), busca el botón Delete Account (Eliminar cuenta). Tócalo y confirma. Tu red y la información asociada se eliminarán de la plataforma de forma irrevocable y permanente.
