# كيف تحذف حسابك

في قسم Account -> Settings (الحساب -> الإعدادات)، ابحث عن زر Delete Account (حذف الحساب). اضغط الزر وأكّد. ستُحذف شبكتك والمعلومات المرتبطة بها من المنصة حذفًا نهائيًا لا رجعة فيه.
