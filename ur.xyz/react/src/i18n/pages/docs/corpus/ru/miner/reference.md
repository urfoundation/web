# Справочник майнера

Краткий справочник по команде `provider`. `provider --help` выводит краткий обзор, `provider <command> --help` объясняет одну команду, а `provider help all` выводит все команды и параметры. Если вы использовали установщик, команда называется `urnetwork`.

## Повседневные команды

В скобках указаны другие имена той же команды.

| Команда | Что она делает |
| --- | --- |
| `provider setup` | Пошагово настраивает это устройство: вход, регистрация, адрес для выплат, фоновая служба. Можно безопасно запускать повторно. `--no-service` пропускает службу, а `--yes --auth-code-file=<path>` выполняет настройку без вопросов (и пропускает адрес для выплат). |
| `provider status` | Настроен ли майнер, запущен ли и подключён ли? Код завершения 0, когда всё в порядке, 3 — когда нужна настройка, 4 — когда майнер не запущен или не подключён. `--json` — для скриптов. |
| `provider doctor` | Почему не удаётся войти или подключиться: папка состояния, DNS, подключение, TLS, часы, обновления. |
| `provider login` (`auth`) | Вход с кодом авторизации, который вводится в скрытом запросе. `provider login <auth_code>` принимает код напрямую, но оставляет его в истории командной оболочки. `--user_auth='you@example.com'` выполняет вход с email вашего аккаунта и запрашивает пароль. |
| `provider start` (`provide`) | Начать майнинг в этом терминале. Первый запуск на новом устройстве спрашивает разрешения перед регистрацией; `--allow-client-registration` регистрирует без вопроса. `provide` выводит полный журнал вместо живого представления. |
| `provider service install` | Запускать майнер в фоне с автоматическими обновлениями: при каждой загрузке в Linux, при входе в систему в macOS и в Windows. Также `start`, `stop`, `restart`, `status`, `logs --follow` и `uninstall`. |
| `provider update` | Обновиться до последнего выпуска. `--check` только проверяет, `--status` показывает настройки автоматических обновлений. См. [Обновления](/docs/miner/updates). |
| `provider --version` | Вывести версию. |
| `provider auth-provide` | Вход и запуск одной командой. |
| `provider wallet challenge '<coldkey_ss58>'` | Вывести заявление, которое нужно подписать для кошелька выплат. |
| `provider wallet set '<coldkey_ss58>' …` | Задать кошелёк для выплат с подписью или файлом seed. См. [Получение оплаты](/docs/miner/rewards#set-your-payout-wallet). |
| `provider claim --epoch=<epoch> --rpc=<url>` | Проверить заявку на вознаграждение пула; добавьте `--key_file`, чтобы отправить её. См. [Получение вознаграждений](/docs/miner/rewards#claim-your-rewards). |
| `provider network` (`choose_network`) | Показать действующего оператора. `provider network use <api_url> <connect_url>` выбирает другого, `provider network reset` возвращает оператора по умолчанию. |
| `provider operators` | Перечислить операторов из опубликованного списка операторов и состояние вашего входа у каждого. |
| `provider proxy add …` | Добавить выходные узлы SOCKS5. См. [Несколько выходных узлов на одном хосте](/docs/miner/advanced#several-exits-on-one-host). |

Команды для всех операторов, кошельков на hotkey, демонов получения и флотов верхнего уровня описаны на странице [Для опытных](/docs/miner/advanced).

## Общие параметры

| Параметр | С чем используется | Что он делает |
| --- | --- | --- |
| `--allow-client-registration` | `start`, `provide` | Разрешить регистрацию нового устройства. Никогда не заменяет идентичность, которая у майнера уже есть. |
| `--port=<port>` | `start`, `provide` | Отдавать [страницу состояния](/docs/miner/run#the-status-page) на этом порту. `0`, значение по умолчанию, выключает её. |
| `--max-memory=<mem>` | `start`, `provide`, `login` | Мягкая цель по памяти в байтах или с `b`, `kib`, `mib` или `gib`. |
| `-v`, `-vv` | с большинством | Больше подробностей в журнале. (Для `urnet-tools` в Linux и macOS `-v` означает `version`; в Windows вводите `urnet-tools version`.) |
| `-f` | `login`, `proxy` | Заменить существующий вход или прокси без вопроса. |
| `--api_url=<url>` | с большинством | Использовать этот URL API оператора для одной команды. |
| `--connect_url=<url>` | `start`, `provide` | Использовать этот URL подключения оператора для одного запуска. |
| `--provider-jwt=<path>` | `wallet`, `claim` | Выбрать, учётные данные какого устройства использовать, — для дополнительных выходных узлов или других операторов. |
| `--wallet=<coldkey_ss58>` | `start`, `provide` | Также задать кошелёк для выплат при запуске, как `wallet set`. Ошибка записывается в журнал и не останавливает майнинг. |

## Команды установщиков

Установщики для Linux, macOS и Windows используют одну общую команду, `urnet-tools`:

| Команда | Что она делает |
| --- | --- |
| `urnet-tools status` | Сводка на одном экране: запущен ли майнер, версия, выполнен ли вход, автоматические обновления. |
| `urnet-tools start`, `stop`, `restart` | Запустить, остановить или перезапустить майнер в фоне. |
| `urnet-tools logs` | Следить за выводом майнера. Ctrl-C, чтобы выйти. |
| `urnet-tools version` | Показать установленную версию и последнюю, если она новее. |
| `urnet-tools update` | Обновиться сейчас, если есть более новый выпуск. В Linux никогда не переходит на более старый. |
| `urnet-tools auto-update` | Показать, включены ли автоматические обновления. Добавьте `on` или `off`, чтобы изменить это, и `--interval 6h`, `daily`, `weekly` или `monthly`, чтобы изменить частоту. |
| `urnet-tools auto-start on`, `off` | Запускается ли майнер сам после перезагрузки (в macOS и Windows — при входе в систему). |
| `urnet-tools reinstall -t <version>` | Установить определённый выпуск. |
| `urnet-tools uninstall` | Удалить майнер и его фоновые задачи. Сохраняет `~/.urnetwork`. Добавьте `--remove-identity`, чтобы удалить и её, после того как введёте `delete`. |

Параметры принимают форму `--interval weekly` или `--interval=weekly`. В Windows работают и написания в стиле PowerShell (`-Interval`, `-RemoveIdentity`), а если PowerShell сообщает, что выполнение скриптов отключено, вводите `urnet-tools.cmd`. См. [Обновления](/docs/miner/updates) и [Работа в фоне](/docs/miner/run#with-an-installer).

Где каждый установщик хранит майнер:

| Система | Папка | Журнал |
| --- | --- | --- |
| Linux | `~/.local/share/urnetwork-provider` | `urnet-tools logs` (журнал systemd) |
| macOS | `~/.local/share/urnetwork-provider` | `~/Library/Logs/urnetwork/` |
| Windows | `%LOCALAPPDATA%\urnetwork\provider` | `provider.log` в этой папке |

## Файлы, которые хранит майнер

Майнер хранит своё состояние в `~/.urnetwork`. Делайте резервную копию всей папки после остановки майнера, храните её в надёжном личном месте и восстанавливайте как единое целое. Не запускайте одновременно две копии одной и той же папки. Потеря или правка файлов идентичности может сделать восстановление устройства невозможным, даже если вход в ваш аккаунт по-прежнему работает.

| Файл или папка | Что в нём хранится |
| --- | --- |
| `jwt` | Вход в ваш аккаунт, записанный `provider login` (`auth`). |
| `.provider.key` и `.provider.key.identity` | Исходный ключ Ed25519 устройства и его маркер идентичности. |
| `.provider.key.registration.lock` | Локальная блокировка для регистрации устройства. |
| `.provider.jwt` | Собственные продлеваемые учётные данные устройства, используемые для кошельков и заявок. |
| `.provider.jwt.registration*` | Сохранённый запрос на регистрацию и состояние восстановления. Сохраняйте каждый из этих файлов. |
| `.provider.jwt.wallet-consent/` | Подписанная история вашего кошелька, включая ещё не отправленные заявления. |
| `.provider.cert`, `.provider.extender.key` | Сертификат устройства и идентичность экстендера, если они есть. |
| `network.json` | Оператор, выбранный через `provider network use` (`choose_network`). |
| `proxy` | Необязательные выходные узлы SOCKS5. |
| `operators.yml` | Последняя исправная копия списка операторов, при `--all-operators`. |
| `operators/<domain>/` | Собственное состояние одного оператора из списка, с файлами, перечисленными выше. |
| `hotkey-wallet/` | Подписанная цепочка выплат через hotkey (`originals.json`) и ожидающее заявление, если оно есть (`pending.json`). |
| `miner.log` | Журнал `provider start` в терминале. |
| `miner-status.json`, `miner-update.json` | То, что читает `provider status`, а также настройки автоматических обновлений и последняя проверка. |

Установщики хранят программу майнера и `urnet-tools` в собственной папке (см. [Команды установщиков](#installer-commands)), отдельно от этой папки.

## Переменные окружения

Для обычной настройки ни одна из них не нужна.

| Переменная | Что она делает |
| --- | --- |
| `URNETWORK_STATE_DIR` | Использовать эту папку вместо `~/.urnetwork`. Удобно, чтобы опробовать тестовое устройство, не трогая настоящее. |
| `URNETWORK_AUTO_UPDATE` | Задайте `0` при запуске `provider service install`, чтобы установить службу с выключенными автоматическими обновлениями. На обновления установщика не влияет. |
| `URNETWORK_AUTH_CODE` | Установщики выполняют вход с этим кодом авторизации, а не запрашивают его. |
| `URNETWORK_CONNECT_EXTRA_ROOT_CA_FILE` | Файл PEM с дополнительными сертификатами CA, которым нужно доверять, для сети, которая инспектирует зашифрованный трафик. Он должен содержать только сертификаты CA. |

## Глоссарий

| Термин | Значение |
| --- | --- |
| Код авторизации (auth code) | Одноразовый код из аккаунта у оператора, с которым компьютер входит в этот аккаунт. |
| Оператор | Сеть, для которой ваш майнер предоставляет выходные узлы в интернет. По умолчанию — `bringyour.com`. |
| Устройство (идентичность провайдера) | Этот компьютер как майнер: идентичность в `~/.urnetwork`, которая не меняется при перезапусках и обновлениях. |
| Coldkey | Ваш кошелёк Bittensor в виде адреса ss58, который начинается с `5`. Вознаграждения выплачиваются на него. |
| Hotkey | Второй ключ Bittensor. Майнеры используют его, чтобы входить сразу ко всем операторам, а флоты — чтобы регистрироваться на верхнем уровне. |
| Эпоха | Период, за который считаются вознаграждения. Расчётная эпоха в mainnet длится около семи дней. |
| Пул | Общая выплата оператора. Большинство майнеров зарабатывают из пула. |
| Верхний уровень | Большие флоты, которые регистрируют собственный hotkey и получают эмиссию майнеров напрямую. |
| Relayer | Ключ EVM, который оплачивает газ за отправку заявки. Вознаграждение он никогда не получает. |
| α ($UR) | Токен подсети, в котором выплачиваются вознаграждения. |
| Momentum | Доля эмиссии майнеров, которая выплачивается сейчас; остальное идёт в [Network Capacity Reserve](/reserve). |
