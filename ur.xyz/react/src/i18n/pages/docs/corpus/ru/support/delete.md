# Как удалить аккаунт

В разделе Account -> Settings (Аккаунт -> Настройки) найдите кнопку Delete Account («Удалить аккаунт»). Нажмите её и подтвердите. Ваша сеть и связанная с ней информация будут безвозвратно и навсегда удалены с платформы.
