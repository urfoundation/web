# مرجع المُعدِّن

مرجع سريع للأمر `provider`. يطبع `provider --help` نظرة عامة قصيرة، ويشرح `provider <command> --help` أمرًا واحدًا، ويطبع `provider help all` كل أمر وخيار. إن استخدمت مُثبِّتًا، فاسم الأمر `urnetwork`.

## الأوامر اليومية

الأسماء بين القوسين أسماء أخرى للأمر نفسه.

| الأمر | ما يفعله |
| --- | --- |
| `provider setup` | يُعدّ هذا الجهاز خطوة بخطوة: تسجيل الدخول، والتسجيل، وعنوان الدفع، والخدمة الخلفية. تشغيله مجددًا آمن. يتخطى `--no-service` الخدمة، ويشغّله `--yes --auth-code-file=<path>` دون أسئلة (ويتخطى عنوان الدفع). |
| `provider status` | هل هو مُعَدّ ويعمل ومتصل؟ رمز الخروج 0 عندما يكون كل شيء على ما يرام، و3 عندما يحتاج إلى الإعداد، و4 عندما لا يعمل أو لا يكون متصلًا. `--json` للسكربتات. |
| `provider doctor` | سبب تعذّر تسجيل الدخول أو الاتصال: مجلد الحالة، وDNS، والاتصال، وTLS، والساعة، والتحديثات. |
| `provider login` (`auth`) | تسجيل الدخول برمز مصادقة يُكتب في موجّه مخفي. يأخذ `provider login <auth_code>` الرمز مباشرة، لكنه يتركه في سجل أوامر الصدفة. يسجّل `--user_auth='you@example.com'` الدخول ببريد حسابك ويطلب كلمة المرور. |
| `provider start` (`provide`) | بدء التعدين في هذه الطرفية. يسأل أول بدء على جهاز جديد قبل تسجيله؛ ويسجّله `--allow-client-registration` دون سؤال. يطبع `provide` السجل الكامل بدلًا من العرض الحي. |
| `provider service install` | تشغيل المُعدِّن في الخلفية مع التحديثات التلقائية: عند كل إقلاع على Linux، وعند تسجيل الدخول على macOS وعلى Windows. وأيضًا `start` و`stop` و`restart` و`status` و`logs --follow` و`uninstall`. |
| `provider update` | التحديث إلى أحدث نسخة. يكتفي `--check` بالتحقق، ويعرض `--status` إعدادات التحديث التلقائي. راجع [التحديثات](/docs/miner/updates). |
| `provider --version` | طباعة النسخة. |
| `provider auth-provide` | تسجيل الدخول والبدء بأمر واحد. |
| `provider wallet challenge '<coldkey_ss58>'` | طباعة البيان الذي يجب توقيعه لمحفظة الدفع. |
| `provider wallet set '<coldkey_ss58>' …` | ضبط محفظة الدفع بتوقيع أو بملف seed. راجع [الحصول على المال](/docs/miner/rewards#set-your-payout-wallet). |
| `provider claim --epoch=<epoch> --rpc=<url>` | التحقق من مطالبة بمكافأة المجمّع؛ أضف `--key_file` لإرسالها. راجع [طالب بمكافآتك](/docs/miner/rewards#claim-your-rewards). |
| `provider network` (`choose_network`) | عرض المشغّل الساري. يختار `provider network use <api_url> <connect_url>` مشغّلًا آخر، ويعيد `provider network reset` إلى الافتراضي. |
| `provider operators` | سرد المشغّلين في قائمة المشغّلين المنشورة وحالة تسجيل دخولك لدى كل منهم. |
| `provider proxy add …` | إضافة نقاط خروج SOCKS5. راجع [عدة نقاط خروج على مضيف واحد](/docs/miner/advanced#several-exits-on-one-host). |

الأوامر الخاصة بكل المشغّلين، ومحافظ الـ hotkey، وخدمات المطالبة، وأساطيل المستوى الأعلى موجودة في صفحة [متقدم](/docs/miner/advanced).

## الخيارات الشائعة

| الخيار | يُستخدم مع | ما يفعله |
| --- | --- | --- |
| `--allow-client-registration` | `start`, `provide` | السماح بتسجيل جهاز جديد. لا يستبدل أبدًا هوية يملكها المُعدِّن بالفعل. |
| `--port=<port>` | `start`, `provide` | تقديم [صفحة الحالة](/docs/miner/run#the-status-page) على هذا المنفذ. `0`، وهو الافتراضي، يوقفها. |
| `--max-memory=<mem>` | `start`, `provide`, `login` | هدف مرن للذاكرة بالبايت، أو مع `b` أو `kib` أو `mib` أو `gib`. |
| `-v`, `-vv` | معظم الأوامر | تفاصيل أكثر في السجل. (مع `urnet-tools` على Linux وmacOS، يعني `-v` الأمر `version`؛ وعلى Windows اكتب `urnet-tools version`.) |
| `-f` | `login`, `proxy` | استبدال تسجيل دخول أو وكيل موجود دون سؤال. |
| `--api_url=<url>` | معظم الأوامر | استخدام عنوان URL هذا لواجهة المشغّل البرمجية لأمر واحد. |
| `--connect_url=<url>` | `start`, `provide` | استخدام عنوان URL هذا لاتصال المشغّل لتشغيل واحد. |
| `--provider-jwt=<path>` | `wallet`, `claim` | اختيار بيانات اعتماد الجهاز التي تُستخدم، لنقاط خروج إضافية أو لمشغّلين آخرين. |
| `--wallet=<coldkey_ss58>` | `start`, `provide` | ضبط محفظة الدفع أيضًا عند البدء، مثل `wallet set`. يُسجَّل الفشل في السجل ولا يوقف التعدين. |

## أوامر المُثبِّتات

تتشارك المُثبِّتات لأنظمة Linux وmacOS وWindows أمرًا واحدًا، هو `urnet-tools`:

| الأمر | ما يفعله |
| --- | --- |
| `urnet-tools status` | ملخص في شاشة واحدة: هل يعمل أم لا، والنسخة، وهل سُجّل الدخول، والتحديثات التلقائية. |
| `urnet-tools start`, `stop`, `restart` | بدء المُعدِّن في الخلفية أو إيقافه أو إعادة تشغيله. |
| `urnet-tools logs` | متابعة مخرجات المُعدِّن. Ctrl-C للخروج. |
| `urnet-tools version` | عرض النسخة المثبّتة، وأحدث نسخة إن كانت أحدث منها. |
| `urnet-tools update` | التحديث الآن، إن وُجدت نسخة أحدث. وعلى Linux لا ينتقل أبدًا إلى نسخة أقدم. |
| `urnet-tools auto-update` | عرض هل التحديثات التلقائية مفعّلة. أضف `on` أو `off` لتغيير ذلك، و`--interval 6h` أو `daily` أو `weekly` أو `monthly` لتغيير وتيرتها. |
| `urnet-tools auto-start on`, `off` | هل يبدأ المُعدِّن من تلقاء نفسه بعد إعادة التشغيل (على macOS وWindows، عند تسجيل دخولك). |
| `urnet-tools reinstall -t <version>` | تثبيت نسخة محددة. |
| `urnet-tools uninstall` | إزالة المُعدِّن ومهامه الخلفية. يحتفظ بـ `~/.urnetwork`. أضف `--remove-identity` لحذفه أيضًا، بعد أن تكتب `delete`. |

تأخذ الخيارات إما الصيغة `--interval weekly` أو `--interval=weekly`. وعلى Windows تعمل أيضًا صيغ PowerShell (`-Interval` و`-RemoveIdentity`)، وإن قال PowerShell إن تشغيل السكربتات معطّل، فاكتب `urnet-tools.cmd` بدلًا من ذلك. راجع [التحديثات](/docs/miner/updates) و[التشغيل في الخلفية](/docs/miner/run#with-an-installer).

أين يحتفظ كل مُثبِّت بالمُعدِّن:

| النظام | المجلد | السجل |
| --- | --- | --- |
| Linux | `~/.local/share/urnetwork-provider` | `urnet-tools logs` (سجل systemd) |
| macOS | `~/.local/share/urnetwork-provider` | `~/Library/Logs/urnetwork/` |
| Windows | `%LOCALAPPDATA%\urnetwork\provider` | `provider.log` في ذلك المجلد |

## الملفات التي يحتفظ بها المُعدِّن

يحتفظ المُعدِّن بحالته في `~/.urnetwork`. خذ نسخة احتياطية من المجلد بأكمله بعد إيقاف المُعدِّن، وأبقِه خاصًا، واستعده كقطعة واحدة. لا تشغّل نسختين من المجلد نفسه في الوقت نفسه. قد يجعل فقدان ملفات الهوية أو تعديلها استعادة الجهاز مستحيلة، حتى لو ظل تسجيل الدخول إلى حسابك يعمل.

| الملف أو المجلد | ما يحتويه |
| --- | --- |
| `jwt` | تسجيل دخول حسابك، الذي يكتبه `provider login` (`auth`). |
| `.provider.key` و`.provider.key.identity` | مفتاح Ed25519 الأصلي للجهاز وعلامة هويته. |
| `.provider.key.registration.lock` | قفل محلي لتسجيل الجهاز. |
| `.provider.jwt` | بيانات الاعتماد الخاصة بالجهاز القابلة للتجديد، وتُستخدم للمحافظ والمطالبات. |
| `.provider.jwt.registration*` | طلب التسجيل المحفوظ وحالة الاستعادة. احتفظ بكل واحد من هذه الملفات. |
| `.provider.jwt.wallet-consent/` | سجل محفظتك الموقَّع، بما في ذلك البيانات التي لم تُرسل بعد. |
| `.provider.cert`, `.provider.extender.key` | شهادة الجهاز وهوية الموسِّع، إن وُجدتا. |
| `network.json` | المشغّل المختار عبر `provider network use` (`choose_network`). |
| `proxy` | نقاط خروج SOCKS5 الاختيارية. |
| `operators.yml` | آخر نسخة سليمة من قائمة المشغّلين، مع `--all-operators`. |
| `operators/<domain>/` | الحالة الخاصة بمشغّل مُدرَج واحد، مع الملفات أعلاه. |
| `hotkey-wallet/` | سلسلة الدفع الموقَّعة عبر الـ hotkey (`originals.json`) وأي بيان معلّق (`pending.json`). |
| `miner.log` | سجل `provider start` في طرفية. |
| `miner-status.json`, `miner-update.json` | ما يقرؤه `provider status`، وإعدادات التحديث التلقائي وآخر تحقق. |

تحتفظ المُثبِّتات ببرنامج المُعدِّن و`urnet-tools` في مجلدها الخاص (راجع [أوامر المُثبِّتات](#installer-commands))، بمعزل عن هذا المجلد.

## متغيرات البيئة

لا يحتاج الإعداد العادي إلى أي منها.

| المتغير | ما يفعله |
| --- | --- |
| `URNETWORK_STATE_DIR` | استخدام هذا المجلد بدلًا من `~/.urnetwork`. مفيد لتجربة جهاز اختباري دون المساس بجهازك الحقيقي. |
| `URNETWORK_AUTO_UPDATE` | اضبطه على `0` عند تشغيل `provider service install` لتثبيت الخدمة والتحديثات التلقائية متوقفة. لا يؤثر في تحديثات المُثبِّت. |
| `URNETWORK_AUTH_CODE` | تسجّل المُثبِّتات الدخول برمز المصادقة هذا بدلًا من طلبه. |
| `URNETWORK_CONNECT_EXTRA_ROOT_CA_FILE` | ملف PEM بشهادات CA إضافية يجب الوثوق بها، لشبكة تفحص حركة المرور المشفّرة. يجب ألا يحتوي إلا شهادات CA. |

## مسرد المصطلحات

| المصطلح | المعنى |
| --- | --- |
| رمز المصادقة (auth code) | رمز لمرة واحدة من حسابك لدى المشغّل يسجّل به الحاسوب الدخول إليه. |
| المشغّل | الشبكة التي يقدّم لها مُعدِّنك نقاط الخروج إلى الإنترنت. الافتراضي هو `bringyour.com`. |
| الجهاز (هوية المزوّد) | هذا الحاسوب بوصفه مُعدِّنًا: الهوية في `~/.urnetwork` التي تبقى كما هي عبر عمليات إعادة التشغيل والتحديثات. |
| Coldkey | محفظتك في Bittensor، في صورة عنوان ss58 يبدأ بـ `5`. تُدفع المكافآت إليه. |
| Hotkey | مفتاح ثانٍ في Bittensor. يستخدمه المُعدِّنون لتسجيل الدخول لدى كل المشغّلين دفعة واحدة، وتستخدمه الأساطيل للتسجيل في المستوى الأعلى. |
| الحقبة | الفترة التي تُحتسب فيها المكافآت. تبلغ حقبة التسوية نحو سبعة أيام على الشبكة الرئيسية. |
| المجمّع | الدفعة المشتركة لمشغّل. يكسب معظم المُعدِّنين من مجمّع. |
| المستوى الأعلى | أساطيل كبيرة تسجّل الـ hotkey الخاص بها وتكسب إصدار المُعدِّنين مباشرة. |
| Relayer | مفتاح EVM يدفع رسوم الغاز لإرسال مطالبة. ولا يتلقى المكافأة أبدًا. |
| α ($UR) | رمز الشبكة الفرعية الذي تُدفع به المكافآت. |
| الزخم (momentum) | حصة إصدار المُعدِّنين التي تُدفع الآن؛ ويذهب الباقي إلى [Network Capacity Reserve](/reserve). |
