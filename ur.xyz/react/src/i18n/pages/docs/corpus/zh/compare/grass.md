# UR 矿工与 Grass 对比

事实核查于 2026-11-18。

本页只比较机制：不提供任一网络的收益数字、预测或代币价格。Grass 的事实来自 [Grass 条款](https://www.grass.io/terms-and-conditions)和[隐私政策](https://www.grass.io/privacy-policy)。关于 UR 的事实来自[如何运行矿工](/docs/miner)、[通过挖矿获得报酬](/docs/miner/rewards)和[研究方法](/research/methodology)。另请参阅[所有网络对比](/docs/compare)。[成为 UR 矿工](/miners)介绍了 UR 这一方。

## 奖励机制的差异

一个处于运营商池中的 UR 矿工获得池的一部分：已完成的使用字节数乘以可靠性，其中可靠性为确认次数除以分配次数。验证者测量这些工作；不存在按字节计算的价格。奖励按周期计算，在主网上约为一周，之后再领取。

Grass 的条款称，奖励取决于你所贡献带宽的在线时间、质量、位置和使用量。积分没有货币价值，条款也不承诺未来的奖励。

## Grass 的优势

- **无需命令行或端口：** Grass 的条款没有描述任何服务器设置。
- **可选择资产：** 奖励除 Grass 代币外还可能包括 USDC。

## 选择 UR 你要放弃什么

- 命令行设置、开放端口，以及一份签名的 Bittensor 钱包声明。
- 每个周期结束后领取，并使用持有少量 TAO 用作 gas 的中继密钥提交。
- 你无法为自己的带宽定价。
- 本页引用的页面没有说明谁对出口流量负责；你的运营商的条款会说明。
