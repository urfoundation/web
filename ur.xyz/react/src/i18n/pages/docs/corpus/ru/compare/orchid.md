# Майнер UR и провайдер Orchid

Факты проверены 2026-11-18.

Эта страница сравнивает только механизмы: здесь нет цифр заработка, прогнозов или цен токенов ни для одной из сетей. Факты об Orchid взяты из [документации Orchid](https://docs.orchid.com/en/latest/), [репозитория Orchid](https://github.com/OrchidTechnologies/orchid) и [политики конфиденциальности Orchid](https://www.orchid.com/privacy-policy). Факты о UR взяты из [Как запустить майнер](/docs/miner), [Получение оплаты за майнинг](/docs/miner/rewards) и [Методология исследований](/research/methodology). См. также [сравнение всех сетей](/docs/compare). [Майнинг Bittensor SN25](/miners) описывает сторону UR в одном месте.

## Рядом

| | Майнер UR | Orchid |
| --- | --- | --- |
| Что вы запускаете | Программа `provider` на компьютере с Linux, macOS или Windows, который остаётся в сети, с одним стабильным публичным адресом и входящим TCP-портом 443 для его extender | Сервер провайдера, внесённый в каталог Orchid в Ethereum; требования к оборудованию не задокументированы |
| Прочие требования | Аккаунт у оператора сети и coldkey Bittensor | OXT в стейке в каталоге |
| Как задаются вознаграждения | Доля эмиссии майнеров подсети, пропорциональная выполненному трафику, умноженному на измеренную надёжность; платный и бесплатный трафик приносят одинаково | Пользователи платят провайдерам вероятностными наноплатежами; провайдеры выбираются случайно, с весом по стейку |
| Актив выплаты | α ($UR) в виде нативного стейка α на вашем coldkey | Сверх наноплатежей не задокументировано |
| Кошелёк или KYC | Coldkey Bittensor, который вы подтверждаете подписанным заявлением; цитируемые страницы не описывают проверки личности | Аккаунт Ethereum; проверка личности не задокументирована |
| Клиент с открытым кодом | Руководство следует исходному коду `sn/miner` на GitHub | Да, AGPL-3.0 |
| Трафик, который вы передаёте | Интернет-трафик оператора сети, в роли его точки выхода | Трафик пользователей Orchid VPN |
| Кто несёт ответственность | Не рассматривается на цитируемых здесь страницах; прочитайте условия своего оператора | Не задокументировано |
| Данные и удаление | Майнер хранит свою идентичность и историю кошелька в `~/.urnetwork`; удаление на цитируемых страницах не рассматривается | Orchid говорит, что не собирает персональных данных; очистка данных приложения удаляет их единственную копию |

## Чем различаются вознаграждения

Майнер UR в пуле оператора получает долю пула: выполненные байты использования, умноженные на надёжность, где надёжность — это подтверждения, делённые на назначения. Эту работу измеряют валидаторы; цены за байт нет. Вознаграждения считаются по эпохам — примерно неделя в mainnet — и забираются после неё.

Orchid — это рынок VPN-провайдеров, а не приложение для обмена резидентным трафиком. Провайдеры ставят OXT в стейк и соревнуются за запросы через случайный выбор, взвешенный по стейку. Пользователи платят офчейн-билетами в стиле лотереи, которые провайдер проверяет перед обслуживанием.

## В чём выигрывает Orchid

- **Заявленная лицензия:** репозиторий распространяется под AGPL-3.0.
- **Обращение с данными описано прямо:** политика конфиденциальности Orchid говорит, что он не собирает персональных данных.

## Чем вы жертвуете с UR

- Настройка в командной строке, открытые порты и подписанное заявление кошелька Bittensor.
- Получение вознаграждений после закрытия каждой эпохи с помощью ключа ретранслятора, на котором есть немного TAO для оплаты газа.
- Нет цены, которую вы задаёте за свою пропускную способность.
- Цитируемые здесь страницы не говорят, кто отвечает за выходной трафик; это говорят условия вашего оператора.
